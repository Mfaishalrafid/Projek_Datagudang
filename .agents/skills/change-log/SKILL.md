# Change Log Tracker Skill

Use this skill every time the project is modified.

The goal is to make all changes easy to review manually, especially before handing the project to a client.

## Main Goal

Every change must be documented clearly, including:
- What changed
- Why it changed
- Which files/folders changed
- What feature or bug was affected
- What commands were run
- What should be manually checked
- Any risks or follow-up notes

## Change Log File

Maintain this file:

```txt
docs/CHANGELOG_CODEX.md
